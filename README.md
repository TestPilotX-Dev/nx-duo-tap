# NX Duo Tap

Módulo para Nintendo Switch con el que **NX Duo** comparte tu partida con un amigo: tu Switch envía la imagen, el sonido y el segundo mando a NX Paradox por USB.

## Descarga

No tienes que instalarlo a mano. **NX Paradox** lo instala en tu microSD y lo mantiene al día, y la app NX Duo Tap de tu Switch te avisa cuando hay una versión nueva.

Las versiones publicadas están en la sección [Releases](../../releases).

Visita [testpilotx.net](https://testpilotx.net/nx-paradox/) para más información.
